# Раскраска для Ани

«Три в ряд»-раскраска: под цветами — холст с пиксельной картиной. Собранный ряд красит клетки под собой своим цветом — только там, где по картине нужен именно он; краска растекается на соседнюю клетку того же цвета. Цель — закрасить всю картину. Без проигрыша: кончились ходы — «ещё 5 ходов».

- Цветы-фишки: роза, подсолнух, василёк, фиалка, сакура, клевер, календула — у каждого своя форма (различимы и без цвета).
- Инструменты: 4 в ряд — кисть (ряд/столбец), уголок — клякса (3×3), 5 в ряд — палитра (все цветы одного цвета).
- 40 картин 8×8 (`levels.js`; живые: в окне победы двигаются — `ANIM`), галерея со звёздами, подсказка через 9 с без хода; котики внизу мурлыкают и подсказывают ход.
- Мастерская: своя картина 8×8 (редактор в галерее) становится уровнем, ходы считает бот (`RL.movesFor`). Свои картины — `localStorage` `rk_mine`.
- Подсказка «на экран Домой» и перенос прогресса (номер картины) в приложение на iPhone.
- Сложность: первые 6 картин — 4 цвета фишек, дальше пятый цвет вводится плавно (вес 0,25 → 1); ходы на картину — по боту.

Файлы: `index.html` (вёрстка), `levels.js` (картины, ходы), `logic.js` (поле, ряды, покраска — без отрисовки), `app.js` (отрисовка, ввод, звук, окна), `sw.js` (офлайн, автообновление).
Проверка: `node selfcheck.js` — правила, спецфишки, покраска, бот проходит все картины; `node selfcheck.js --calibrate` — таблица ходов.
Локально: сервер `raskraska` в `Games/.claude/launch.json` (порт 8782); `?debug` — доступ к состоянию для проверок.
